# Germany Simulator

The canonical standalone repository for the “Grand Theft Amt” browser game.

- Play: https://georgefejer91.github.io/GermanySimulator/
- Original EC Games route: https://ec-games.space/games/germany-simulator/
- 3D renderer diagnostic: https://georgefejer91.github.io/GermanySimulator/3d.html

The root game progressively uses a Three.js world with local gray-tinted CC0 building meshes and falls back to its playable pseudo-3D canvas renderer when WebGL or the loader is unavailable. The game is served directly from the repository root. Project context and agent instructions live in [`For-AI/`](./For-AI/README.md).
