# Germany Simulator

The canonical standalone repository for the “Grand Theft Amt” browser game.

- Play: https://georgefejer91.github.io/GermanySimulator/
- Original EC Games route: https://ec-games.space/games/germany-simulator/
- 3D renderer diagnostic: https://georgefejer91.github.io/GermanySimulator/3d.html

The root game uses a required Three.js world with local gray-tinted 3D models, code-native 3D stand-ins for missing individual models, and registered bitmap sprites for the authored political characters. The retired Canvas world is no longer a runtime fallback. The game is served directly from the repository root. Project context and agent instructions live in [`For-AI/`](./For-AI/README.md).
