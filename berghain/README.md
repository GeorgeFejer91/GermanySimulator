# Berghain reconstruction

Research and authoring workspace for a realistically scaled, detailed 3D reconstruction of Berghain's exterior and interior.

- [Goal, work plan and current status](For-AI/README.md)
- [Online resource catalogue](For-AI/SOURCES.md)
- [Interior design, artworks and sound-system inventory](For-AI/INTERIOR.md)
- [Hidden model viewer](model.html) — direct-link only; reconstruction in progress.
- [Geheim avatar walkthrough](https://germanysimulator.de/geheim/) — walk outside with WASD/arrows or touch, drag to look, then use E or the entrance button to enter and leave. Unlisted; uses the same provisional model.

This scope belongs to the existing Germany Simulator project. Model fidelity must be supported by references, with undocumented geometry identified explicitly.
