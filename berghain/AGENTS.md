# Berghain reconstruction workspace

Read the repository [AGENTS.md](../AGENTS.md), [agent start](../For-AI/AGENT-START.md), then [this workspace's guide](For-AI/README.md). This folder owns the requested Berghain architectural reconstruction, reference catalogue and hidden model viewer. It is an asset-authoring scope within Germany Simulator.

Keep the goal, acceptance checklist and current handoff in `For-AI/README.md`; keep external references and uncertainty in `For-AI/SOURCES.md`. Record source dates and distinguish measured architecture, photographs, eyewitness diagrams and inferred geometry. Never describe an incomplete or inferred interior as a verified digital twin.

The requested viewer is `model.html`, direct-link only, excluded from normal navigation and indexing. It is an architectural asset viewer, not another game. Reuse the project's existing local Three.js dependency. Shipped model assets stay in the root `assets/` authority; authoring/reference files and tools may live here. Keep third-party research downloads separate from licensed shipped media.

Shared [asset policy](../For-AI/ASSET-POLICY.md), [object consistency](../For-AI/OBJECT-CONSISTENCY.md), [skill routing](../For-AI/SKILLS.md), and silent browser testing apply. Scope acceptance to the viewer; changing the main game requires reading the [city guide](../levels/city/For-AI/README.md) and assigning affected root files. Preserve unrelated local changes.
