01. THE PRODUCT WE ARE FINISHING
==========================================================================

Germany Simulator is the existing standalone browser-based 3D bureaucratic
open-world parody, "Grand Theft Amt". It has a fictional three-day deadline,
forms, missions, city travel, neighbors, offices, quizzes, wanted/police systems,
keyboard and mobile touch controls, authored satire, recorded voices and
browser audio. Berlin behind the Brandmauer speaks regional Denglisch; outside
it, German remains the character language even when UI language is English.

Keep the existing product identity, mission/reward ownership, regional voices,
controls and desktop/mobile behavior. Registered painted sprites are intentional
people in the Three.js world. Do not replace them with generic meshes. The
player and police have their retained 3D exception; do not turn them into two
new painted-character jobs. Device-tilt control was removed; do not restore it.

Technical architecture:
  - One static deployable runtime tree at repository root.
  - index.html is the canonical root game entry.
  - 3d.html is a compatibility entry redirecting to index.html and retaining
    query parameters and URL hash. It is not a second game controller.
  - game.js owns simulation, mission state, collision, ordinary NPC updates,
    player input mediation, rewards, and the city/interior callbacks.
  - world3d.js owns Three.js rendering, camera, visibility, asset presentation,
    sprite-host ownership, and the simulation-to-render bridge.
  - assets/ is the single shipped asset authority.
  - Existing static JavaScript, vanilla Three.js r186 and asset admission queues
    remain the architecture. No new engine, service, navigation framework,
    duplicate asset database or runtime directory is justified by this backlog.
  - The personal Rust/Tauri default concerns new desktop apps. It is not a
    request to migrate this browser game.

Completion means playable, correctly owned and verified behavior in the actual
game, not just valid files, generated pictures, passing regexes or an ending
state assigned by a test. Preserve provenance, licensing and exact text/audio
ownership. Keep implementation/provenance explanations out of player dialogue.
