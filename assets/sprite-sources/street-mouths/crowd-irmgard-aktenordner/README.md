# Irmgard Aktenordner mouth registrations

This is the already integrated orange-haired `crowd-irmgard-aktenordner`, with
the burgundy binder. It is distinct from held `stadt-irmgard-aktenstapel` art.

`anchors-v1.json` records five hand-measured lip views on the exact desktop
delivery, three occluded views with no mouth, and a separate standing-source
fit. `registrations-v1.json` retains the per-cell source, transported contours,
paint-alignment diagnostics and complete357-slot inventory. No body pixels change.

Run `python tools/build-irmgard-mouths.py` with the existing NumPy/Pillow/SciPy
authoring environment. It writes candidates and CPU previews to ignored
`output/ambient-city-animation/irmgard-mouths/`; it never edits the main manifest.
The runtime uses canonical128x160 axes and scales them to each decoded delivery.
Cell-local UV fractions are unchanged. Both exact delivery hashes are bound.

Root inspected all260 visible source/closed/open CPU cells on22 light boards,
all260 open cells on four dark edge boards, the complete357-slot head inventory,
and both standing close-ups. Mouths stay attached to the own painted lips;
identity, hair, binder and silhouette remain intact. Rear/occluded/unused97 cells
have no mouth registration. Seven alignment solves reached their evaluation
limit (121,288,290,291,316,318,319); their actual final source fits were inspected.
Solver convergence and RGB error are diagnostics, not anatomical approval.

This source review permits the runtime candidate review. It does not establish
GPU alpha/depth, native recorded speech, changing-pose timing or mobile quality.
Those results belong to the existing task's independent reviews and SESSION.md.
The original body, stride25.6, pivot and locomotion remain authoritative.
