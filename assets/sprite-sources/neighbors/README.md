# Fictional miniature neighbors

The final generated direction sheet contains Heiko Maaslos, Inga Maaslos and Frau Schwabingen. Rows identify characters; columns are front, right profile and rear. The left profile mirrors the right. Only original fictional artwork ships here.

Style contract: compact proportions matching the existing miniature cast, restrained detail, brown zip sweater, teal corporate blazer, and a practical checked apron/headscarf. Heiko and Frau Schwabingen remain arrogant and unsmiling. Inga has a coherent, mildly superior face with naturally aligned eyes, rounded cheeks and one clean closed mouth.

Build with tools/build-neighbor-sprites.py (Python, Pillow and NumPy). It keeps one figure scale per family, a shared 128 x 192 cell and (64,180) planted pivot; each desktop/mobile export has 16 distinct phases for down/right/up/left/idle/talk. Complete shoe layers use transparent-gap seams, linear planted stance and smooth lifted recovery. Mobile filtering clears low-alpha gutters. Runtime cycle distances are recorded in assets/characters/neighbors/manifest.json and matched in neighbor-sprites.js.

Built-in image generation produced the original direction paint; the final prompt asked for compact established-game proportions, simplified fictional faces, aloof self-importance and a house-proud Swabian work costume. Authoring trials and final-frame evidence remain outside shipped assets.
