# Frau Knick bridge paintings

Five transparent source outputs from the built-in OpenAI image generator,
2026-10-08. The existing four-anchor contact sheet supplied character identity.
Exact prompts are in prompts.json and reach-prompt.txt; source hashes and
sizes are in provenance.json. No CLI generation or third-party image source.

Ten exported paintings bridge ready → raised → contact → refusal → ready.
The first stamping-strip cell is unused: reach.png replaces it with an explicit
paper pickup. tools/prepare-knick-bridges.py registers full figures with uniform
strip scales, fixed ground alignment and transparent padding. No limbs were
cut out or separately resized. The previews retain the four original anchors.

Preview registration and its known stepped/proportion limitations are documented
in assets/previews/knick-splats/README.md. These sources are not runtime inputs.
