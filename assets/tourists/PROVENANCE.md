# Accepted animations: Germans on vacation

These are the two user-approved Germany Simulator Germans on vacation, Herr and Frau Sandale, carrying towels. The user requested their new four-direction walks and corner turns as the standard game manifestation. The original front figures came from the game's retained pre-rig towel sprites; missing whole-body views were produced with built-in ImageGen, corrected against accepted neighbouring views, then animated from intact painted source pixels. The towel remains on the anatomical right arm. Fixed viewer-right foreground footwear is the user's accepted choice for this pair.

Each current atlas is1536×3952 RGBA with192×208 cells. Its first ten rows preserve all68 accepted walking/turn/bridge cells pixel for pixel:32 walk phases,16 planted turning poses and20 stop/start bridge frames. Nine appended rows contain57 reaction/look cells, for125 active cells per character. Timing, shared pivot[96,203], all12 directed paths and context-free transition cores are in each manifest. Walking advances from actual ground distance; complete the stride, freeze the ground position through the timed core, then resume target phase0. This uses the existing Three.js sprite texture path, with the original archived images as missing-file fallback. No new engine, backend, skeleton runtime, morphing or ghosting crossfade is involved.

The connected Tower file tool supports UTF-8 writes but no binary writes. The PNG's original bytes are split into static base64 JSON transport parts, assembled once with native browser APIs. These parts reconstruct the exact reviewed image; they are not independent artworks. Both local reconstruction and transfer receipts were checked; the loader checks the decoded PNG hash when Web Crypto is available. Authoring Python libraries do not ship to the game.
