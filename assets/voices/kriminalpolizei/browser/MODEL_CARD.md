# Compact caller name derivative

This model generates only the visitor's name in the Kripo opening greeting. The surrounding words are prerecorded, and the rest of the conversation keeps its selected original recordings. The user listened to the actual browser-generated George Fejer greeting on 2026-10-13 and accepted it as “good enough”; its audio hash is recorded in the manifest.

The model retains stable voice ID `kriminalpolizei`, selected profile `f700170f840543bca7413d3ccf6ac028` and the selected original/normalized-reference hashes. Its teacher is pinned OpenVoice V2 tone conversion of German Thorsten Piper speech, using the accepted shipped phone recording as the tone reference. The user accepted both original-reference and shipped-recording teacher examples before distillation.

Private authoring generated 187 teacher examples (21.69 minutes) and eight disjoint heldout greeting names. Training starts from the original German base, freezes pronunciation and latent flow, and adapts the posterior encoder/decoder and training discriminator for 2,000 global steps. All 507 frozen tensors remain byte-equal to the base. The manifest owns teacher/source/embedding/checkpoint/packing hashes; private corpora, teacher weights and large training checkpoints remain outside the shipped game.

The compressed model is 16,033,482 bytes; decoded ONNX is 18,849,196 bytes. INT8 stored weights expand to floating-point inference. One WASM SIMD thread runs in a background worker, without WebGPU. Sentence priors provide pronunciation context; only the name plus sixteen removable context frames pass through the vocoder. Two fixed greeting parts total 139,864 bytes.

Eleven native CPU name probes took 0.110–0.203 seconds (median 0.156 seconds) on this laptop with two threads. All eight heldout names and Erika Mustermann/Anna Müller passed unprompted large-v3 transcription of the actual packed name-plus-recording joins. George Fejer was transcribed as George Fehr; the user heard the actual browser greeting and accepted it. These checks do not establish universal pronunciation, peak memory, every browser, or physical-phone speed.

Preparation starts at the first usable companion name, including a supplied opening-form prefill. Six fixed call recordings warm in native media buffers at that point. Answer starts a ready greeting immediately and continues into the fixed body. If synthesis is unsupported, unavailable or unfinished, Answer plays the complete original recorded introduction and question. A greeting that fails before playback also uses that backup; a failed cropped body gets one bounded retry with the complete opening. Call-owned static spans clip transitions. The shared manager owns RAM-only model/Blob caches, worker teardown and strict profile/text receipts. Slot completion/pagehide releases speech and media buffers. No speech data is saved to user folders or app-owned persistent storage.

OpenVoice source/model revisions are in the manifest; its [MIT license](LICENSE-OpenVoice) is bundled for attribution. The pretrained German source and runtime notices are shared with [the appointment model card](../../knick/browser/MODEL_CARD.md) and [the voice provenance ledger](../../LICENSES.md). Existing selected phone recordings retain their original provenance and licensing terms.
