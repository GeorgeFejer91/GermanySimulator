# Opt-in candidate dialogue preview

These 201 MP3s are selected **review candidates**, generated with Chatterbox Multilingual V2 0.1.7 (model revision `5bb1f6ee58e50c3b8d408bc82a6d3740c2db6e18`, MIT model terms) from hash-verified CC0 EmoDB references. This includes 114 fixed-character/Bürgeramt lines, twelve city police barks and four Bürgeramt phone lines for Heinrich Wachtmeister, 36 barks owned by twelve separately named moving crowd actors, and 35 inner-monologue lines for Hans-Peter Mustermann. Each entry in `manifest.json` records the exact line, named `voiceId`, saved Secret Tunnel profile UUID, reference hash, output hash, and independent ASR result. The original EmoDB audio is not included here. Its per-character source filenames, speaker IDs, labels, and hashes are in `For-AI/VOICE-CAST.json`.

Open the game with `?voicePreview=1` and enable voices to audition candidates in city NPC dialogue, Bürgeramt character/clerk scenes, police barks, named moving towel-pedestrian barks, and player inner speech. The Bürgeramt QR invitation carries this preview flag to the phone, where Heinrich's four exact phone lines use the same named profile and timing receipts. Normal gameplay keeps the existing speech path and browser voice choices. A candidate is chosen only for an exact `(voiceId, text)` match; a missing or failed recording falls back to browser speech. The unlisted crowd and player lines had changed or ambiguous words in independent transcription and are still being worked on. Speech remains tied to the visible dialogue and is cancelled when the cue changes.

Independent German ASR matched 149 of 201 selected lines word-for-word after case and punctuation normalization. The other 52 still need listening and possible retakes, especially mixed German/English words and written clock times. **None of these clips is release-cleared merely because it appears in this preview.** Listen to all 201 for exact words, identity, emotion, artifacts and reference echo before enabling any clip by default. Source emotion labels are selection evidence, not proof that generated output retains validated valence/arousal.
