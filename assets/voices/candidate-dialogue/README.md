Its per-character source filenames, speaker IDs, labels, and hashes are in `For-AI/VOICE-CAST.json`.

Open the game with `?voicePreview=1` and enable voices to audition candidates in city NPC dialogue, Bürgeramt character/clerk scenes, police barks, named moving towel-pedestrian barks, and player inner speech. The Bürgeramt QR invitation carries this preview flag to the phone, where Heinrich's four exact phone lines use the same named profile and timing receipts. Normal gameplay keeps the existing speech path and browser voice choices. A candidate is chosen only for an exact `(voiceId, text)` match; a missing or failed recording falls back to browser speech. Every currently authored fixed-character, clerk, police, named-crowd bark, and player inner-monologue line has an opt-in candidate; several selected takes still have changed or ambiguous words under independent transcription and need listening or retakes. Speech remains tied to the visible dialogue and is cancelled when the cue changes.
