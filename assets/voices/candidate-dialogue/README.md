# Opt-in candidate dialogue preview

These 114 MP3s are selected **review candidates**, generated with Chatterbox Multilingual V2 0.1.7 (model revision `5bb1f6ee58e50c3b8d408bc82a6d3740c2db6e18`, MIT model terms) from hash-verified CC0 EmoDB references. Each entry in `manifest.json` records the exact line, named `voiceId`, saved Secret Tunnel profile UUID, reference hash, output hash, and independent ASR result. The original EmoDB audio is not included here. Its per-character source filenames, speaker IDs, labels, and hashes are in `For-AI/VOICE-CAST.json`.

Open the game with `?voicePreview=1` and enable voices to audition candidates in city NPC dialogue and Bürgeramt character/clerk scenes. Normal gameplay keeps the existing speech path. A candidate is chosen only for an exact `(voiceId, text)` match; a missing or failed recording falls back to browser speech. Speech remains tied to the visible dialogue and is cancelled when the cue changes.

Independent German ASR matched 78 of 114 selected lines word-for-word after case and punctuation normalization. The other 36 still need listening and possible retakes, especially mixed German/English words. **None of these clips is release-cleared merely because it appears in this preview.** Listen to all 114 for exact words, identity, emotion, artifacts and reference echo before enabling any clip by default. Source emotion labels are selection evidence, not proof that generated output retains validated valence/arousal.
